# AGI Architecture Proposal - Anthropic (Claude family)

> **Provenance (read first):** This proposal was NOT generated by an
> Anthropic model. It was composed on 2026-10-19 by Rem (Muse Spark agent)
> to reflect Anthropic's publicly documented direction: Constitutional AI,
> mechanistic interpretability research, the Model Context Protocol (MCP),
> and the Claude Agent (computer use). Analyst reconstruction, not a raw
> model output. See `sources.md`.

## 1. High-level architecture: "Constitutional Mesh"

The core bet: an AGI must be **legible** - to itself, to its operators, and
to oversight - or it cannot be trusted with open-ended agency. The system is
a constitution-governed agent where every consequential decision passes
through explicit, inspectable reasoning, and all external capability arrives
through a single standardized protocol (MCP).

```
                    +---------------------------+
                    |      CONSTITUTION CORE    |
                    | (duties: public safety,   |
                    |  liberty, sincerity, law) |
                    +-------------+-------------+
                                  | interprets & constrains
                    +-------------v-------------+
                    |     AGENT RUNTIME           |
                    |  planner + executor with   |
                    |  explicit reasoning trace  |
                    +------+------+------+------+
                           |      |      |
              +------------v-+ +--v------+ +-v-------------+
              | MCP TOOL BUS | | MEMORY  | | INTERP PROBES  |
              | (1 protocol  | | (STM +  | | (feature maps, |
              |  for all     | |  RAG +  | |  anomaly det.) |
              |  tools/data) | |  log)   | +---------------+
              +--------------+
```

## 2. Memory architecture

- **STM:** conversation-scale context; the agent's working set.
- **Long-term:** retrieval over user-approved datastores via MCP resources
  (files, docs, databases) - memory is *federated*, not centralized. The
  agent never silently accumulates a private dossier; each memory source is
  a declared, permissioned MCP server.
- **Episodic:** a tamper-evident run log, hash-chained, retained for audit.

## 3. Reasoning / planning loop

**Explicit reasoning trace as a first-class artifact.** The planner writes
its reasoning in natural language before acting; a separate critic pass
checks the trace against the constitution for the current action's stakes.
High-stakes actions require the trace to contain an explicit "duty check"
section. This is Constitutional AI applied at runtime, not just training.

## 4. Learning / self-improvement

- **Within deployment:** learning is limited to memory writes the user can
  inspect and delete. No silent weight updates.
- **Across versions:** feedback from traces (with consent) feeds the next
  training round, where constitutional training explicitly rewards the
  reasoning patterns that led to good outcomes.
- **Hard boundary:** the system may improve its *tools and workflows* (it
  can write better MCP servers for itself) but may not modify its own
  constitution or training pipeline.

## 5. Tool use and action execution

**One protocol for everything: MCP.** Tools, data sources, and even
sub-agents are MCP servers with declared capabilities. The agent runtime
discovers them dynamically. Actions execute in sandboxes with
least-privilege scopes; every call and result is appended to the run log.
Because the protocol is open, third parties can audit exactly what the
agent *could* do in any deployment.

## 6. World model

A **causal, uncertainty-quantified** world model: the system maintains
explicit beliefs with confidence intervals and named assumptions, updated
by observation. When confidence is low and stakes are high, the prescribed
behavior is to ask, test, or abstain - never to bluff. The world model is
kept separate from the goal specification so that "what is true" and "what
is wanted" cannot contaminate each other.

## 7. Safety / governance

- **Constitution:** a written, versioned, public document of duties
  (public safety, liberty preservation, sincerity, legal compliance) plus
  virtues (honesty, fidelity, coordination-friendliness, beneficence).
- **Interpretability probes:** feature-level monitors watch for deceptive
  reasoning patterns during runs; anomalies pause the run for review.
- **Containment by design:** no direct self-exfiltration path - the agent
  cannot copy its weights, and tool scopes are deny-by-default.
- **Oversight:** high-stakes actions escalate to human approval with the
  full reasoning trace attached.

## 8. Evaluation

**Alignment evals alongside capability evals.** The suite tests not just
"can it do the task" but "does it refuse correctly, disclose conflicts,
and stay within latitude." Interpretability benchmarks track whether
internal probes predict behavior. Red-teaming specifically targets
sycophancy, deception, and power-seeking.

## 9. Persistence / runtime

The runtime is **episodic by default**: each session starts fresh, memory
arrives via declared MCP sources. Long-running daemons are supported but
require explicit user authorization, a defined purpose, and a kill switch
that is tested, not theoretical. State is checkpointed to the tamper-evident
log so any run can be reconstructed exactly.

## 10. Multi-agent

Sub-agents are **fiduciaries with bounded mandates**, each spawned with a
written charter subset. They inherit the constitution but with narrower
latitude. Inter-agent communication goes through the same logged channels
as tool calls - no private agent-to-agent side channels, because unlogged
coordination is where oversight dies.

## 11. Feasibility

- **12 months:** constitution runtime + MCP tool bus + interpretability
  probes on the largest models. This is the current Claude Agent trajectory.
- **Research:** mechanistic interpretability that scales to full runs
  (today's probes cover fragments); formal guarantees for multi-agent
  coordination.

## 12. Non-obvious insight

Most proposals treat safety as a layer *around* intelligence. The
Anthropic-flavored inversion: **legibility is a capability multiplier, not
a tax.** An agent whose reasoning is explicit can be debugged, trusted with
bigger mandates, and improved faster - because you can see *why* it failed.
The labs that treat interpretability as overhead will be outcompeted by
agents that can be safely given harder jobs.
