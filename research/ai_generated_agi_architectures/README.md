# AI-Generated AGI Architecture Proposals - Research Packet

## Overview

This packet collects, preserves, and compares AGI architecture proposals
generated by AI systems, in response to the research bounty
([original](https://github.com/aLexzzz430/Cognitive-OS/issues/5),
[mirror](https://github.com/zhangjiayang6835-cyber/bounty-plaza/issues/477)).
The goal is not to paste generic AI answers, but to produce an auditable
research packet that makes different architecture ideas comparable and
useful for Cognitive-OS planning.

## Collection Method

- **Standardized prompt**: one fixed prompt (v1.0, see `prompts.md`)
  applied unchanged across all 8 collection runs, covering 11 architecture
  dimensions (memory, reasoning/planning, learning, tool use, world model,
  safety, evaluation, persistence, multi-agent, feasibility, originality).
- **Distinct stances**: each run was asked to take a different architectural
  stance (memory-centric, swarm, predictive world-model, neuro-symbolic,
  continual learning, OS-level tool use, safety-first, minimalist) so the
  proposals represent genuinely different design philosophies.
- **Verbatim preservation**: raw responses saved as-is; only markdown
  formatting normalized. Provenance per run in `sources.md`.
- **Honest scope note**: all 8 runs in this packet were generated by a
  single model family (Muse Spark, Meta) on 2026-10-19. See `sources.md`
  for the full disclosure and the extension plan for multi-provider
  collection.

## Headline Findings

1. **Three schools emerged**: the *substrate school* (intelligence lives in
   organized experience - runs 01, 06), the *model school* (intelligence
   lives in the model or its update rule - runs 03, 05, 08), and the
   *organization school* (intelligence lives in structure and checks -
   runs 02, 04, 07).
2. **Universal consensus**: every proposal includes retrieval over past
   experience, a planning/execution split (or deliberate simplification),
   tools as the action channel, and human approval for irreversible
   actions.
3. **Deepest split**: where intelligence lives (memory vs. world model vs.
   update rule vs. environment vs. base model) - five different answers,
   the most important open question in the packet.
4. **Safety matured from values to mechanisms**: proof obligations,
   capability budgets, simulation gates, compartmented memory - not just
   "we'll add RLHF".
5. **Actionable recommendation for Cognitive-OS**: see `synthesis.md` -
   a phased reference architecture combining file-based substrate,
   tiered memory, contract-checked tools, critic quorum, and gated
   continual learning, with a maintained minimalist baseline.

## Directory Structure

- `README.md` - this file
- `prompts.md` - the exact standardized prompt (v1.0), version history,
  adaptation log, collection protocol
- `raw_outputs/` - 8 verbatim architecture proposals (one per run)
- `comparison.csv` - structured comparison across 11 dimensions x 8 runs
- `summary.md` - synthesis of common patterns, disagreements, notable ideas
- `synthesis.md` - proposed combined architecture for Cognitive-OS planning
- `sources.md` - model names, provider, access dates, honest provenance
  disclosure, known limitations
