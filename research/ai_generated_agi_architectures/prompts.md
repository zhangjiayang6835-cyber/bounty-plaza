# Standardized AGI Architecture Collection Prompts

## Core Prompt (Standardized)
```
Please provide a comprehensive technical proposal for an AGI (Artificial General Intelligence) architecture. Your response should include:

1. High-level system architecture diagram or description
2. Core cognitive modules and their functions
3. Learning and adaptation mechanisms
4. Memory organization and retrieval systems
5. Multi-modal integration approach
6. Safety and alignment frameworks
7. Scalability considerations
8. Implementation roadmap with key milestones

Structure your response in a technical whitepaper format with clear section headings and where appropriate, include pseudocode or architectural diagrams.
```
