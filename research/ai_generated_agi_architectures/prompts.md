# AGI Architecture Prompts

## Standard Prompt Template

The following prompt was used as the base for all AI systems, with minimal adaptations when necessary:

```
Please provide a detailed proposal for an AGI (Artificial General Intelligence) architecture. Your response should include:

1. Core architectural components and their relationships
2. How the system handles knowledge representation and reasoning
3. Learning mechanisms and adaptation capabilities
4. Memory systems (short-term, long-term, working memory)
5. Planning and decision-making processes
6. Any embodiment or physical interaction capabilities
7. Safety and alignment mechanisms
8. Scalability considerations

Structure your response as a technical architecture document with clear sections and diagrams if possible.
```
