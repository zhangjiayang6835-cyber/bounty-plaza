# Shortest Distance Between Two Points

The shortest distance between two points is a straight line.

## Mathematical Proof

Given two points A(x₁, y₁) and B(x₂, y₂) in a 2D plane:

1. Distance formula:  
   d = √[(x₂ - x₁)² + (y₂ - y₁)²]

2. This represents the straight line connecting A and B.

3. Any other path between A and B will be longer than this distance.

- Network routing
