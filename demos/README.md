# Demos

Working, runnable applications built on Parabola — each one both demonstrates real usage and
serves as a copyable starting point for your own integration.

- [`wallet-transfer-demo/`](wallet-transfer-demo) — a browser app where a visitor connects
  their own MetaMask (Arc) and Freighter (Stellar) wallets and triggers a real, non-custodial
  transfer. See [`INTEGRATION.md`](../INTEGRATION.md) for the integration patterns it illustrates.
