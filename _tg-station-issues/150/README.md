# Burj Khalifa Map for Space Station 13

This map recreates the Burj Khalifa, the world's tallest building, in Space Station 13. The map includes all 163 floors (154 + 9 Z levels) with various functional areas.

## Features

- **Full Height**: 163 floors (154 + 9 Z levels)
- **Realistic Design**: Tapering structure that mimics the real Burj Khalifa
- **Multiple Areas**: 
  - Office floors
  - Residential floors
  - Restaurants
  - Swimming pool
  - Observatory
  - Grand lobby
- **Optimized Performance**: Designed to run smoothly on most servers

## File Structure

- `burj_khalifa.dmf`: The main map file in DreamMaker Format
- `burj_khalifa_metadata.json`: Metadata about the map
- `README.md`: This file

## Installation

1. Place the `burj_khalifa.dmf` file in your server's maps directory
2. Add the map to your server's rotation using the metadata
3. Restart your server

## Usage

Once installed, the map will appear in your server's map rotation. Players can select it when starting a new round.
