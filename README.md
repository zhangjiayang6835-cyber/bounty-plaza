# OmniBlocks SaaS Mode

A Next.js application implementing SaaS (Software as a Service) mode for the OmniBlocks platform.

## Features

- **Multi-tier subscription plans** - Starter, Professional, Enterprise
- **Usage-based billing UI** - Monthly and yearly billing cycles
- **Dashboard analytics** - Real-time stats display
- **Feature showcase** - Platform capabilities overview
- **Responsive design** - Works on all device sizes

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
