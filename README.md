# Bounty Plaza

A curated collection of open‑source bounties that can be claimed, solved, and verified on‑chain. Each bounty is documented in its own markdown file under the `bounties/` directory.

## How to Contribute

1. **Find a bounty** – Browse the `bounties/` folder or check the [Agent Bounties](https://agentbounties.app) platform.  
2. **Claim** – Comment `/claim` on the corresponding GitHub issue to lock the bounty for 24 h.  
3. **Solve** – Deliver the required artefact (code, design, research, etc.).  
4. **Submit for verification** – Follow the verification link provided in the bounty description.  
5. **Get paid** – Once verified, the reward is released automatically.
