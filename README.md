# Bounty Plaza

![Bounty](https://img.shields.io/badge/Bounty-$1000-brightgreen)
![Status](https://img.shields.io/badge/Status-Open-brightgreen)

This repository hosts a collection of bounty tasks that are open for contributors to claim and complete.  
Each issue in the repository is a bounty that can be claimed by adding a comment with `/claim`.  
Once claimed, the issue is locked for 24 hours to allow the contributor to work on it.

## How to claim a bounty

1. Find an open issue that interests you.  
2. Comment `/claim` on the issue.  
3. The issue will be locked for 24 hours and you will be the sole claimant.  
4. Complete the task and submit a pull request that resolves the issue.  
5. Once the PR is merged, the bounty will be paid out according to the reward policy.

## Reward policy

See the [REWARD_POLICY.md](REWARD_POLICY.md) file for details on how bounties are paid out, including the distribution of coins and USD rewards.

## Contributing

Feel free to fork the repository, create a new issue for a new bounty, or contribute to existing ones.  
All contributions are welcome and will be reviewed promptly.
