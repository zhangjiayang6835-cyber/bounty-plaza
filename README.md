# TG Station TypeScript Transpilation

This repository contains the transpiled version of the TG Station codebase from Dream Maker to TypeScript.

## Status

This is a work in progress. The goal is to transpile the entire codebase from Dream Maker to TypeScript, making it easier to maintain and run in a modern browser environment.

## Getting Started

```bash
# Install dependencies
npm install

# Build the project
npm run build

# Run in development mode
npm run dev
```

## Project Structure

```
src/
  ├── types/          # TypeScript type definitions
  ├── engine/         # Game engine implementation
  ├── gamemodes/      # Game mode definitions
  ├── mobs/          # Mobile entity definitions
  ├── objects/        # In-game object definitions
  ├── areas/          # Area definitions
  ├── tgs/            # TG Station specific code
  └── utils/          # Utility functions
```
