# Bounty Plaza

A platform for claiming and completing bounties on GitHub.

## Overview

Bounty Plaza allows developers to claim coding challenges and submit pull requests for rewards. Each bounty has a difficulty rating, coin reward, and real-world USD value.

## How It Works

1. Browse available bounties
2. Comment `/claim` to lock a task for 24h
3. Submit a PR that resolves the issue
4. Receive coin rewards upon merge
